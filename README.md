# BD2-TPI-Grupo80
Desarrollo de Trabajo Practico Integrador de BD relacionales

Explicación del sistema: 
 

El sistema será una aplicación que se encargará de la gestión de un emprendimiento textil, y su base de datos guardará la información de los productos, sus ventas y clientes. Esto le permitirá al usuario encargado poder ver el estado de un producto especifico, pudiendo tener la información completa y reciente del mismo. 

Funcionalidades 

El usuario podrá: 

Buscar a través de un ID, un producto, cliente o una venta. 

Realizar altas, bajas y modificaciones de productos o clientes. 

Visualizar estadísticas de ventas según periodos de tiempo preseleccionados (ventas totales o de un producto especifico). 

En caso de ser requerido, ofrecer descuentos por promociones en ciertas fechas preseleccionadas y/o superando un monto de compra establecido anteriormente. 

El sistema contará con una base de datos relacional que contendrá la información de productos, clientes, ventas y promociones.
